# 프로젝트 리뷰

다음 문서를 먼저 읽는다.

- `/AGENTS.md`
- `/docs/ARCHITECTURE.md`
- `/docs/ADR.md`

그런 다음 변경된 파일을 확인하고 다음을 검증한다.

1. ARCHITECTURE.md에 정의된 디렉토리 구조를 준수하는가?
2. ADR에 정의된 기술 선택을 벗어나지 않았는가?
3. 새 기능에 대한 테스트가 작성되어 있는가?
4. AGENTS.md의 CRITICAL 규칙을 위반하지 않았는가?
5. 빌드 명령이 오류 없이 통과하는가?

다음 형식으로 결과를 작성한다.

| 항목 | 결과 | 비고 |
|------|------|------|
| 아키텍처 준수 | ✅/❌ | {상세} |
| 기술 스택 준수 | ✅/❌ | {상세} |
| 테스트 존재 | ✅/❌ | {상세} |
| CRITICAL 규칙 | ✅/❌ | {상세} |
| 빌드 가능 | ✅/❌ | {상세} |

위반 사항이 있으면 파일과 위치를 근거로 수정 방안을 구체적으로 제시한다.
